- ML listings are product-in-channel registration: Destinos › Mercado Livre (`aba=ml`) shows only registration slices; price mismatch and broken link are Conciliação rules (`ml_preco_diferente`, `ml_vinculo_quebrado` in `divergencia_regra` + `vw_conciliacao_fila`), mirroring Shopify's cadastro × conserto split.
- Product is born only through the catalog sheet v2 (Conciliação › Novos → `fn_catalogo_nascer_da_planilha`); no screen calls fn_nascer_produto / fn_nascer_produtos_lote / fn_pi_efetivar_lote directly, and old entry links (`cadastro-pi`, `/vendas/produto/importar-pi`) redirect to Novos, so there is one door for product creation.
- Each Conciliação view answers one question: a rule's screen comes only from `divergencia_regra.superficie` (dim `divergencia_superficie_dim`); new fila branches go into `vw_conciliacao_fila_todas`, and `vw_conciliacao_fila` / `vw_conciliacao_pendencia_cadastro` only filter it, so moving a rule between views is a data change, never code.
